# Flods
Few lines of dom state management

## Purpose
Create a few-lines, no-dependencies, very minimal, DOM state management for single page web apps.


## Build
Builds a dist with webpack:

    npm run build

Eventually update package.json `version` value

## Run samples

    cd samples/card-done/
    

## Export components

```js
export const { LayerTree, LayerTree$ } = types.LayerTree;
```



```js
export const { Page, Page$ } = fewd.types.Page = Page;
```
